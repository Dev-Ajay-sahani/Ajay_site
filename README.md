# 🏛️ Sarkari Babu — Free All-in-One Govt Job & Document Studio

**Sarkari Babu** is a free, high-performance, 100% client-side web application suite engineered specifically for Indian government job applicants (SSC, UPSC, IBPS, Railways, NTA NEET/JEE, State PSCs) and everyday users seeking reliable PDF and Image editing tools.

---

## ⚡ Key Highlights & Core Capabilities

- **🏛️ Sarkari Babu Identity**: Dedicated to helping every government job applicant meet strict portal requirements effortlessly.
- **🌙 Seamless Dark & Light Mode**: Automatic system theme detection with instant 1-click header toggle and `localStorage` persistence.
- **👁️ 100% Live Visual Previews**: Real-time visual feedback across every tool before downloading.
- **💧 Foolproof Watermark Studio**: Simple 3-step watermark stamping with live opacity, placement styles, and 1-click JPG/ZIP/PDF downloads.
- **🔒 100% Client-Side Privacy**: All processing (cropping, downsampling, binarization, PDF merging/splitting, ZIP generation) executes **locally inside your browser**. Zero data or files are sent to any remote server.
- **🚀 100% GitHub Pages Ready**: Zero backend required. Host directly on GitHub Pages for free!

## 🛠️ Complete Tools Suite (20+ Tools)

### 🇮🇳 Sarkari Exam Portals
1. **PAN Card Photo & Signature** (2.5×3.5 cm at 200 DPI, <50KB & <20KB)
2. **SSC Photo with DOP Banner** (Candidate Name & Date of Photo on bottom strip)
3. **UPSC CSE & NDA Studio** (3.5×4.5 cm at 300 DPI, 20–300 KB)
4. **Passport & Postcard Photo Maker** (300 DPI single photo + printable A4 sheets with 4/8/16/32 copies)
5. **Thumb Impression Enhancer** (High-pass binarization contrast extractor for IBPS/Police forms)
6. **Photo + Signature Joiner** (Combined 350×500 px single file for UPSSSC/MPPEB)
7. **Document & Marksheet Scanner** (Cleans shadows and yellow tints from 10th/12th/Caste certificates)
8. **Sarkari Age Calculator** (Calculates exact age as on recruitment cutoff date)
9. **Exam Specifications Handbook** (Searchable directory of 30+ official exam rules and dimensions)

### 📄 PDF Tools
1. **Merge PDF** (Combine multiple PDFs with visual cover thumbnail previews)
2. **Split PDF** (Extract specific pages with interactive visual page grid thumbnails)
3. **PDF to High-Res JPG** (Convert all PDF pages into crisp images with ZIP download)
4. **Watermark PDF** (Stamp text watermarks across all pages with live Page 1 preview)
5. **Rotate PDF** (Fix orientation with real-time animated rotation preview)
6. **JPG to PDF** (Batch compile multiple images and documents into a clean PDF)

### 🖼️ Image Tools
1. **Compress to Target KB** (Hit exact limits like <20KB, <50KB, <100KB with live quality slider)
2. **Watermark Image Studio** (Stamp custom text or logo with live preview and batch ZIP/PDF export)
3. **Resize Image** (Scale photos by exact pixel dimensions or percentage scale with live preview)
4. **Format Converter** (Batch convert PNG ↔ JPG ↔ WEBP with solid white background replacement)
5. **Photo Color & Clarity Studio** (Adjust Brightness, Contrast, Saturation, and Grayscale filters)
6. **Meme Generator** (Create viral memes with top and bottom text overlay)

## 🚀 How to Host on GitHub Pages

1. Push this folder to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Sarkari Babu Studio"
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. Go to **Repository Settings** → **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`!
